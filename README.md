# pair-wise-yf-50 灾后需求评估与任务分派离线前端

源提示词摘要：评估员在弱网环境离线记录家庭需求、特殊照护和现场说明，团队负责人合并重复记录、分派复核任务并追踪进展；多人修改同一记录时提供字段级冲突展示，不静默覆盖。安置点床位按占用账管理：每个安置点有核定床位容量，离线分配带设备顺序号排入待同步队列，联网后按提交先后合并、先排的先算数；超核定容量的分配转入超员待调整并写明超出几人；核定床位调整后未确认分配按新容量重算、已确认超员项退回待处理；同步中途断网可续传，重连只补做剩余部分，同一份回传不会重复占床。

## 技术栈

Nuxt3、TypeScript、Naive UI、Pinia、Nuxt路由、Axios、VueUse、VeeValidate、Zod、Vue I18n。

## 本地运行

```bash
npm install
npm run dev
npm run build
```
