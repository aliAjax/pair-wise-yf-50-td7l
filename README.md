# pair-wise-yf-50 灾后需求评估与任务分派离线前端

源提示词摘要：评估员在弱网环境离线记录家庭需求、特殊照护和现场说明，团队负责人合并重复记录、分派复核任务并追踪进展；多人修改同一记录时提供字段级冲突展示，不静默覆盖。

## 安置占用账

家庭需求记录、安置分配与派工任务共用一本占用账：

- 每个安置点有核定床位容量；只有「已确认」的分配进正式名单、占床位。
- 离线分配带设备顺序号排入待同步队列，联网后按提交先后合并，先排的先算数。
- 超过核定容量的分配不进正式名单，转「待调整」并写明超出几人，等负责人调整容量或撤销。
- 负责人调整核定床位后：未确认分配按新容量重算；已确认的超员项退回待处理（最晚确认的先退）。
- 同步中途断网可接着重试：已确认的和没合完的都保留，重连只补做剩下的；同一份回传凭申请编号去重，不重复占床位。
- 安置分配离线排入时自动生成「安置入住对接」派工任务。

规则验证：`npx vite-node test-occupancy.ts`（21 条断言）。
